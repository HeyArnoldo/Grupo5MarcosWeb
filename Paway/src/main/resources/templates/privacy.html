Datos personales

Aviso de privacidad

Información sobre el manejo de datos en esta demostración.

Aplicación de prueba. No ingreses datos reales. Este aviso describe el comportamiento técnico de la demostración y no reemplaza una política de privacidad para un servicio comercial.

Datos utilizados

La aplicación de ejemplo contiene perfiles y envíos precargados. Los formularios permiten introducir datos de destinatario y detalles del paquete; usa únicamente valores ficticios durante las pruebas.

Dónde se guardan

Los envíos de demostración se almacenan en memoria en el proceso de la aplicación. La sesión del navegador mantiene temporalmente el perfil seleccionado y, si corresponde, la cotización pendiente. Los datos en memoria se restablecen al reiniciar el sistema.

Alcance

Esta versión no implementa una base de datos ni un flujo de autenticación con contraseña. Este aviso no afirma que cubra todos los tratamientos, proveedores o derechos aplicables a un servicio desplegado.

Referencias normativas

Para preparar una política antes de operar un servicio real, revisa la Ley de Protección de Datos Personales y su reglamento vigente, además de recibir asesoría adecuada para el tratamiento concreto.
