SEMANA 1 · FUNDAMENTOS

Construye una base sólida para desarrollar en la Web

HTML aporta significado, CSS define la presentación y JavaScript incorpora comportamiento.

Domina primero los estándares web; después comprenderás mejor cualquier framework.

Tecnologías fundamentales

HTML

Estructura el contenido y expresa su significado.

CSS

Controla el diseño, los colores y la adaptación.

JavaScript

Permite responder a acciones y modificar la interfaz.

Herramientas del navegador

Permiten inspeccionar el DOM, leer la consola y medir cómo se carga la página.

Buenas prácticas desde el inicio

  • Usar elementos semánticos.
  • Separar responsabilidades.
  • Diseñar para teclado y pantallas pequeñas.
  • Verificar antes de entregar.

Mi meta de aprendizaje

Mi meta de esta semana es entender qué responsabilidad cumple cada archivo antes de apoyarme en un framework. Quiero llegar a Bootstrap sabiendo escribir el HTML semántico y el CSS adaptable por mi cuenta, para reconocer qué me está resolviendo la herramienta y qué decisiones siguen siendo mías.
