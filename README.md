# Grupo5MarcosWeb

Repositorio del Grupo 5 para los trabajos y laboratorios del curso de desarrollo web.

## Estructura

```
.
├── README.md
└── Laboratorio1/     # Primer laboratorio del curso
```

## Cómo trabajar en el repositorio

1. Clonar el repositorio:

   ```bash
   git clone https://github.com/HeyArnoldo/Grupo5MarcosWeb.git
   cd Grupo5MarcosWeb
   ```

2. Crear una rama para tu trabajo:

   ```bash
   git checkout -b laboratorio1/<tu-nombre>
   ```

3. Guardar los cambios y subirlos:

   ```bash
   git add .
   git commit -m "feat(laboratorio1): descripción del cambio"
   git push origin laboratorio1/<tu-nombre>
   ```

4. Abrir un Pull Request hacia `main` para que el grupo revise antes de integrar.

## Convenciones

- Cada laboratorio vive en su propia carpeta: `Laboratorio1`, `Laboratorio2`, etc.
- Los mensajes de commit siguen el formato `tipo(alcance): descripción`.
- No subir archivos generados ni carpetas de dependencias (`node_modules`, `dist`).
